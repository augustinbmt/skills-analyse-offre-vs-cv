---
description: Rédige une lettre de motivation personnalisée pour une offre, à partir de ton CV (PDF ou DOCX)
argument-hint: "[url-de-l-offre] [chemin-du-cv.pdf|.docx]"
---

Charge le skill `lettre-motivation`.

Lis $ARGUMENTS :
- une URL → l'offre visée
- un chemin de fichier .pdf ou .docx → le CV
- aucun argument → reprendre l'offre et le CV déjà utilisés dans la conversation

S'il n'y a de CV ni dans les arguments ni dans la conversation, le demander en PDF ou en DOCX avant de rédiger.
